# Neural model

The model has 96 synthetic units, 14 input channels and a seeded sparse recurrent graph. Approximately 20% of presynaptic units have inhibitory outgoing weights. Seed 7 is the default. There is no anatomical or behavioral fit.

Each 1 ms step decays synaptic state with a 10 ms time constant, adds the previous step's recurrent spikes, and clips the resulting current to [-2, 2]. Available neurons integrate:

`v <- v + dt / tau_m * (-v + external_current + synaptic_state)`

`tau_m = 20 ms`. External current is twice the sparse input projection of button states clipped to [0, 1]. Threshold is 1; a spike resets voltage to zero and imposes a 3 ms refractory interval. The API returns spike counts for each observation interval. Fractional observation durations accumulate, so 60 updates of 1/60 s integrate exactly 1,000 model steps.

This is a numerical visualization model. Spike counts are generated by these equations, not sampled from an animal. The graph, neural spatial coordinates and weights are synthetic and fixed. No loss function, reward or learned controller is implemented. Output never reaches the game.
